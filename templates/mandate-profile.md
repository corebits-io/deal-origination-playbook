# Mandate Profile

> This is the most important file in the system. Every skill reads it.
> Fill it out once, honestly, in plain language. Ten minutes here saves hours.
>
> Copy this file into your workspace folder as `mandate-profile.md` and edit it
> there. Do not commit it. It is yours.
>
> If a field does not apply, write `N/A`. If you do not know yet, write `TBD`.
> Never invent a number to fill a blank — the agents treat `TBD` as "ask the
> user" and are instructed never to fabricate around it.
